> Client-side PDF editor — merge, split, annotate, compress, protect & more. No uploads, no server.

## Quick Start

**Live at:** [pdf.genius-space.org](https://pdf.genius-space.org)

## Supported Input

| # | Type | Notes |
|:-:|------|-------|
| 1 | PDF | Single or multi-page, including password-protected files |
| 2 | JPEG / JPG | Converted to a single-page PDF |
| 3 | PNG | Converted to a single-page PDF |
| 4 | WebP | Converted to a single-page PDF |
| 5 | GIF | Converted to a single-page PDF |

## Features

| # | Feature | Description |
|:-:|---------|-------------|
| 1 | Merge & Reorder | Combine multiple PDFs and drag pages into any order |
| 2 | Split / Delete | Remove individual pages or export a subset |
| 3 | Rotate | Rotate any page in 90° increments |
| 4 | Crop | Visually crop individual pages with draggable handles |
| 5 | Annotate | Draw, add text, highlights, and stamps on any page |
| 6 | Stamp / Signature | Draw a signature or upload an image and place it on a page |
| 7 | Watermark | Apply a diagonal text watermark across all pages |
| 8 | Page Numbers | Add customisable page numbers to all pages |
| 9 | Header / Footer | Add custom text headers and footers with dynamic tokens |
| 10 | Insert Blank | Insert a blank page matching the size of adjacent pages |
| 11 | Resize to A4 | Rescale pages to standard A4 dimensions |
| 12 | Fill Form | Detect and fill PDF form fields interactively |
| 13 | Redact | Permanently black out sensitive text or areas |
| 14 | Password Protect | Encrypt the PDF with a password applied at download time |
| 15 | Remove Password | Strip encryption from password-protected PDFs |
| 16 | Compress | Reduce file size with adjustable quality and rasterisation options |
| 17 | Share | Generate a temporary share link and QR code |
| 18 | Image Import | Convert JPEG, PNG, WebP, or GIF directly into PDF pages |

## Controls

- **Add Files:** Drop PDFs or images onto the upload zone, or use the file picker
- **Drag to Reorder:** Drag page thumbnails to rearrange the page order
- **Select Pages:** Click thumbnails to select; use Select All / Deselect for bulk actions
- **Rotate:** Rotates selected pages 90° clockwise
- **Crop:** Opens a visual crop editor for the selected page
- **Annotate:** Opens the annotation editor — draw, highlight, add text or stamps
- **Fill Form:** Detects form fields and lets you type values before baking them in
- **Redact:** Paint over content on a page to permanently hide it
- **Watermark:** Applies a diagonal text watermark to every page
- **Page Numbers:** Adds page numbers at a chosen position and start offset
- **Header / Footer:** Adds up to three columns of text at the top and/or bottom
- **Insert Blank:** Inserts a blank page next to the selected page
- **Resize to A4:** Rescales all pages to 210 × 297 mm
- **Password:** Set or remove a password — encryption is applied at download time
- **Compress:** Choose quality level and whether to rasterise; downloads a compressed copy
- **Download PDF:** Exports the final merged and edited PDF
- **Share:** Builds and compresses the PDF, then generates a QR code share link

## Requirements

**Browser:** Any modern browser (Chrome, Firefox, Safari, Edge)  
**Server:** None — fully static, runs 100% client-side  
**Dependencies:** Loaded via CDN (PDF.js, pdf-lib, JSZip, Font Awesome, Google Fonts)
